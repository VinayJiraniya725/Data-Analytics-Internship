# Project 3 – SQL Data Analysis

## Project Overview
This project focuses on analyzing an e-commerce dataset using SQL. The objective is to extract useful business insights from the dataset using SQL queries.

## Key SQL Skills Used
- SELECT statements
- WHERE filtering
- ORDER BY sorting
- GROUP BY and HAVING
- DISTINCT
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- CASE statements for categorization
- Subqueries
- Window functions: RANK, DENSE_RANK, ROW_NUMBER
- Revenue and sales analysis
- Customer analysis
- Product analysis
- Monthly and yearly analysis

## Analysis Performed

### Basic Data Analysis
- Displayed records and selected specific columns
- Calculated total orders, unique customers, and unique products
- Identified different payment methods, order statuses, and referral sources
- Calculated minimum, maximum, and average unit price

### Sales and Product Analysis
- Calculated total sales/revenue
- Calculated average order value
- Analyzed product-wise sales and quantity
- Identified highest- and lowest-selling products
- Found top products by sales and quantity
- Calculated product-wise sales percentage

### Customer Analysis
- Calculated total spending by customer
- Identified top customers by sales
- Found customers with more than 5 orders
- Categorized customers as One-Time, Regular, or Frequent
- Identified customers whose spending was above average

### Time-Based Analysis
- Analyzed sales by year
- Analyzed sales by month
- Calculated monthly quantity and average order value
- Identified the year and month with the highest revenue
- Compared yearly and monthly sales performance

### Marketing and Order Analysis
- Analyzed payment methods
- Analyzed order statuses
- Analyzed referral sources
- Compared coupon usage with sales
- Identified the most frequently used coupon code

### Advanced SQL Analysis
- Used subqueries to compare values with overall averages
- Ranked products by total sales
- Found top 3 products
- Ranked customers by total spending
- Found the highest-selling product for each year
- Found top 3 products for each year

The main objective of this project is to practice SQL data analysis and extract meaningful insights related to sales, products, customers, orders, payments, referrals, and revenue.
